# Crime Patterns Across Indian Cities: An Interactive Dashboard for Data-Driven Public Safety

**Motivation:** 
This project is motivated to assist in making data-driven decisions to aid the public safety. With a complex set of data simplified into a visual interactive dashboard, it is hoped to deliver to law enforcement, city planners, and policymakers a tool to: 
- Determine the cities and the areas of crime that should be addressed the most.
- Examine the correlation between the deployment of the police, type of crimes, and the demographics of victims.
- Learn the trends in seasonal or monthly crime to maximize the allocation of resources.
- Learn the profile of victims (age group and gender) in order to formulate specific prevention methods.

**Limitations / Disadvantages:**
- Granularity of Data: This is restricted to City level. It does not provide more detailed information (such as district, neighbourhood, or GPS coordinates), so it is impossible to analyze the hotspots on a map in detail.
- Context Data: This data does not contain important context. To illustrate, it does not contain the data of city population. Lacking this, the calculation of a crime rate (number of crimes/100,000 people) is impossible. This renders it unjust to compare the big city such as Mumbai to the smaller one.
- Data Scope: The analysis is done on one CSV file. It is only reported crimes and does not take into consideration the unreported cases. It also does not have other pertinent information, such as the number of officers, court convictions, or the census demographics.
